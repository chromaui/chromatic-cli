# Codebase map — chromaui/chromatic-cli

| Path | Purpose |
|---|---|
| `.github/` | CI workflows (lint/test, release, smoke tests, Chromatic builds) + composite `actions/setup` (Node 22, corepack, yarn install) |
| `.storybook/` | Storybook config for the repo's own addon/test harness (main.ts, preview.ts, clackCapture) |
| `action-src/` | Source for the GitHub Action wrapper (`chromaui/action`); compiles into `action/` |
| `bin-src/` | CLI command entry points: `init`, `trace`, `turbosnap` manifest, `reactNativeBuild`, `generateManifest`, `trimStatsFile` |
| `node-src/` | Core CLI logic: `tasks/` (build orchestration), `git/`, `io/` (upload/network), `lib/`, `renderer/`, `ui/` (addon UI), `context.ts`, `share.ts`, `errorMonitoring.ts` |
| `scripts/` | `release.mjs`, `releaseNext.mjs`, `publishAction.mjs` (auto-release tooling) |
| `smoke-tests/` | Separate pnpm workspace that runs the built CLI against sample stories |
| `static/` | Static CSS assets shipped with the addon |
| `docs/` | `DEVELOPMENT.md` — local dev, staging/dev backends, release process |
| `action/`, `dist/` | Build outputs (gitignored) — regenerated by `yarn build` / `yarn publish-action` |

Root files: `package.json` (scripts of record), `yarn.lock` (Yarn 4), `tsconfig.json`, `tsdown.config.ts`, `vitest.config.mts`, `eslint.config.mjs`, `action.yml`, `.env.example`, `.tool-versions` (Node 22.22.3).
